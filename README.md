# Portfolio

Source for [arturfbrandi.github.io](https://arturfbrandi.github.io) — a single-page portfolio built with plain HTML/CSS/JS (no build step).

## Structure

- `index.html` — page content
- `css/style.css` — styles (light/dark via `prefers-color-scheme`)
- `js/main.js` — small progressive enhancement
- `assets/` — images and favicon

## Local preview

Open `index.html` directly in a browser, or serve it:

```sh
python3 -m http.server 8000
```

## Deploy

Published via GitHub Pages from the `main` branch.
