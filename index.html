AI Hardcore Engineer — Getnet Multi-Agent Support System

  • Python
  • LangGraph
  • FastAPI
  • RAG
  • Qdrant
  • PostgreSQL
  • Docker

A production-style multi-agent customer support system built for the AI Hardcore Engineer challenge. Four specialized agents — Router, Knowledge, Customer Support, and Human Escalation — plus a Response Synthesizer are orchestrated as a LangGraph state machine over the MiniMax-M3 reasoning model, with agents running in parallel when a request needs both. The Knowledge Agent answers from a RAG index built on Qdrant; the Customer Support Agent uses typed, authorization-scoped tools over a synthetic Postgres backend; requests that can't be resolved safely are escalated to a human. Guardrails run on both input and output.

Farmoria

  • Unity
  • C#
  • Solo dev
  • Game design
  • Project management

An indie game. The player shipwrecks on an island and washes up on an abandoned farm that's been overrun by monsters and sealed off from the rest of the island by the locals. The core loop: clear the farm, build it back up, befriend the islanders, descend into a cave, and take down what's waiting at the bottom — with farming, livestock, mining, fishing, and rich NPCs along the way. Built solo in Unity, with a spec-driven development process for every feature.
